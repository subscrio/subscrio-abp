# Security policy

## Supported versions

Security fixes are applied to the latest released version of `Subscrio.Abp` on NuGet.

## Reporting a vulnerability

Please report security issues privately. Do not open a public GitHub issue for a vulnerability.

- Email: security@subscrio.com
- Or use GitHub Security Advisories in the [subscrio-abp repository](https://github.com/subscrio/subscrio-abp/security/advisories/new)

Include the affected version, impact, and steps to reproduce. We will acknowledge the report and coordinate a fix and disclosure timeline.
